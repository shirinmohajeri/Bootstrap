# 🚀 Bootstrap 5 Practice Project

A beginner-friendly Bootstrap 5 project created to practice responsive web design and Bootstrap components.

---

# 📚 Topics Practiced

## ✅ Bootstrap Grid System
- Responsive columns
- `container`, `row`, `col`
- Column sizing:
  - `col-sm`
  - `col-md`
  - `col-lg`

## ✅ Column Offset
- Using:
  
```html
offset-5
```

to align content and create spacing.

---

# 🖼 Responsive Images

Practiced responsive Bootstrap images using:

```html
<img class="img-fluid">
```

## Features Used

| Class | Description |
|---|---|
| `img-fluid` | Responsive image |
| `rounded` | Rounded corners |
| `rounded-circle` | Circle image |
| `float-end` | Align image right |
| `shadow` | Shadow effect |

# 📂 Dropdown Menu

Created a Bootstrap 5 dropdown menu.

## Important Bootstrap 5 Change

Bootstrap 4:

```html
data-toggle="dropdown"
```

Bootstrap 5:

```html
data-bs-toggle="dropdown"
```
